· 创建用户后，启动应用需选择用户登录
· 账号与角色仅保存在本机，适合团队共用一台工作机的场景
用户名角色状态操作
未启用多用户（单用户模式）
角色权限说明： 管理员 = 全部页面 + 用户管理 + 系统设置； 操作员 = 监控 / 流管理 / 地址生成 / 拉流转推 / 节点 / 消息； 只读 = 概览 / 监控查看 / 质量图表 / 实时预览 / 消息 / 文档

登录身份与管理员口令

未创建任何用户时为单用户模式，权限由登录页选择的身份决定：管理员可见全部菜单，普通用户仅可见查看类菜单。选择管理员需验证口令，口令仅保存在本机。
· 未设置口令时，登录页选择管理员无需验证；设置后必须正确输入才能以管理员身份进入。
· 忘记口令：删除本机配置后重新设置，或在登录页改用「普通用户」身份进入。

日志与数据清理

使用说明

· 实时监控：查看当前所有正在推流的直播间，支持 FLV / HLS 预览与强制断流。
· 拉流转推：将直播流或点播文件拉取后推送到任意推流地址，支持定时开始/结束与点播循环轮播。
· 预览播放器脚本（flv.js / hls.js）在播放时按需从 CDN 加载；若网络受限，可复制播放地址用 VLC 等本地播放器打开。
· 控制台原网页：console.cloud.tencent.com/live
